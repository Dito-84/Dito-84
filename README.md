## Featured projects

**[Hip & Knee Replacement Outcomes Dashboard](https://github.com/Dito-84/hip-knee-replacement-outcomes-dashboard)** · [live dashboard](https://dito-84.github.io/hip-knee-replacement-outcomes-dashboard/)

Complications, readmissions and length of stay after hip and knee replacement, built on the CMS complication-measure definitions. Originally a Qlik Sense app on de-identified hospital data; rebuilt in Python on synthetic data so it can be shared, with safeguards that keep real patient data out of the repository.
