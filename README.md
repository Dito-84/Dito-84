## Featured projects

**[Hip & Knee Replacement Outcomes Dashboard](https://github.com/Dito-84/hip-knee-replacement-outcomes-dashboard)** · [live dashboard](https://dito-84.github.io/hip-knee-replacement-outcomes-dashboard/) · [on AWS](https://d12lu6oeqxy46k.cloudfront.net)

Complications, readmissions and length of stay after hip and knee replacement, built on the CMS complication-measure definitions. Originally a Qlik Sense app on de-identified hospital data; rebuilt in Python on synthetic data so it can be shared, with safeguards that keep real patient data out of the repository. Also deployed on AWS as infrastructure as code: S3 and CloudFront hosting, keyless GitHub deploys through OIDC, and an S3-triggered Lambda that checks uploaded data files, with least-privilege IAM and automated security checks.

`Python` `pandas` `Plotly` `pytest` `GitHub Actions` `AWS CDK` `S3` `CloudFront` `Lambda` `IAM`
